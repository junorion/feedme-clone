# 한글 본문의 LLM URL 넘기기 길이 한도

- 증상 후보: `?q=`로 넘기는 기준이 글자 수(6,000자)라서, 한글은 퍼센트 인코딩 후 URL이 약 54,000자가 된다. ChatGPT·Claude의 실제 URL 한도에서 질문란이 비거나 잘릴 수 있다.
- 근거: 한글 1자는 인코딩 후 9바이트. 실제 서비스 동작은 아직 확인하지 않았다(스펙의 가정).
- 다음 단계: 두 서비스에서 한글 긴 본문으로 실제 한도를 재고, 기준을 인코딩 후 길이로 바꿀지 사용자와 결정한다. 기준 상수는 `components/converter/llm-handoff.ts`의 `URL_HANDOFF_LIMIT`.
