왜 Markdown인가

Markdown은 일반 텍스트로 서식을 표현하는 방법입니다. 문서가 어디로 옮겨 가도 구조가 깨지지 않기 때문에 개발 문서와 블로그에서 널리 쓰입니다. 자세한 규격은 CommonMark 명세에 정리되어 있습니다.

자주 쓰는 문법

  • # 제목은 # 개수만큼 단계가 내려갑니다.
  • 목록은 -로 시작하고, 번호 목록은 1.로 시작합니다.
  • 코드는 백틱 세 개로 감쌉니다.
const res = await fetch("/api/convert", {
  method: "POST",
  body: JSON.stringify({ url }),
});
읽는 사람이 먼저입니다. 서식은 그다음에 고민해도 늦지 않습니다.
